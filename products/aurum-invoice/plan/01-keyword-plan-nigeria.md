# 01. Keyword plan for Nigeria

Priorities are judgement, not measured volume (see README). **P1** = do first, **P2** = next, **P3** = later.
"Page" is where the search is answered. *(new)* means the page is specified in file 02 or 03.

## How Nigerian business owners search (use these words)
- They say **"sample"** and **"format"** as often as "template": "invoice sample", "receipt format", "quotation format".
- They say **"generator"** and **"maker"** for tools, and add **"free"** and **"online"**.
- They use local names: **waybill** (delivery note), **LPO** (local purchase order), **proforma**, **cash invoice** / **sales invoice** (the printed booklet), **receipt book**.
- They add **"in Nigeria"**, **"naira"** or **"PDF"** / **"Word"** / **"Excel"**.
- They search by trade ("invoice for tailor") and by problem ("client refuse to pay", "how to ask customer for money politely").
- Most searches are on a phone. Many come from WhatsApp and Instagram sellers.

Write for these words naturally. Use the main phrase once in the title, once in the H1 or first paragraph, and in one subheading. Never repeat it in every sentence.

## Never target (and never write pages for)
- **"Fake receipt", "fake alert", "bank transfer receipt generator", "OPay / PalmPay / Kuda / Moniepoint receipt generator".** These searches are for forging bank payment proof. Aurum makes a business's own receipts, never imitation bank receipts. If such a word appears in Search Console, do not write for it.
- **City pages** ("invoice app Lagos", "invoice app Abuja"). The app is the same everywhere, so these would be thin copies and can pull the whole site down.
- **The single words** "invoice", "receipt". Not winnable, and not useful.
- **Accounting, payroll, inventory, POS** terms. Aurum does not do these. Saying so plainly (as llms.txt already does) builds trust.
- **Competitor brand names in titles.** Comparison content is allowed only as described in file 02, section 6.

## Avoiding pages that fight each other
One search, one page. Before adding a page, check the tables above. If an existing page already owns the search, improve that page instead. Known pairs to keep apart:
- "receipt sample" belongs to the receipt template guide; the receipt maker page is about the tool.
- "waybill" belongs to the new waybill guide; the delivery-note-vs-invoice guide links to it and does not define waybill at length.
- "LPO" belongs to the new LPO guide; the purchase order guide links to it.
- "free invoice generator" belongs to the new page; the invoice app page links to it.

## Review after real data arrives
Six weeks after Search Console is verified, open **Performance > Queries** and:
1. List queries where Aurum shows in positions 8 to 30. Improve those pages first (add the missing phrase, a clearer answer, a sample).
2. List queries with impressions but no matching page. Those become the next guides.
3. Compare with this plan. Move priorities up or down. Bring the list to Fable if the picture is very different.
