# Aurum ad kit

| File or folder | What it is |
|---|---|
| `clips/` | 11 real recordings of the app, vertical 1080 × 1920 MP4, no sound. A gold ripple shows each tap. |
| `references/` | Pictures to attach when you use the AI image tools (envelope, seal, client page, thank-you card, documents, screens). |
| `mock-phone-alert.png` | A mock-up of the phone alerts, with the real alert wording, for videos. It's a picture, not a screenshot of a phone, so don't call it a real screenshot. |
| `1-AD-IMAGE-PROMPTS.md` | Style block plus 3 ad image prompts, and the exact text to add in Canva. |
| `2-LOGO-PROMPT.md` | A detailed prompt for a new logo, plus the set to ask for. |
| `3-VIDEO-EDIT-PLANS.md` | 5 video plans with timings and on-screen text, no presenter needed. |

All the sample business names and clients in the clips are made up ("Adaeze Couture" and others). Don't present them as real customers.
